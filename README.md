# Cinema-Noir
2nd-sem Database course project by Shaheer Hassan, Moiz Hakro, and Saim Abdullah. A RESTful movie database API in pure Java — no frameworks, just the JDK's built-in HTTP server. Search/filter movies by title, year, genre, and actor; view full details with cast, genres, and reviews; plus signup/login, watchlists, and ratings, all backed by MySQL.
